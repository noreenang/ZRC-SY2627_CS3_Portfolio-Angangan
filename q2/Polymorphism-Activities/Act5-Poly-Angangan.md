1. What do all the methods (move(), special_move(), use()) in the previous activities have in common?

Answer: They have the same method names in different classes and allow objects to perform different actions.


2. How does this activity show polymorphism in a gaming context?

Answer: It shows polymorphism because different characters and items can perform different actions using the same method.


3. Can you think of other examples where the same action behaves differently depending on the character or item?

Answer: An attack action can work differently depending on the character. A warrior uses a sword, while a mage uses magic.
